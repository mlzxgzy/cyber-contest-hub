紧凑版改动要点

  • 顶部 80px → 48px：图标/标题/按钮改 small 尺寸；入库步骤条从独立一行（约76px）压缩为标题栏内胶囊组，整体省约 110px。
  • 标签导航：card 型 → line 型，44px → 34px，去掉图标后的横向空间也更省。
  • 卡片：去掉 32px 大图标块，改用 8px 色点；卡片头 46px → 30px；「上传/新增」等操作按钮全部上收到卡片头右侧，正文更矮。
  • 表单：字段两列网格排布，label 间距减半；附件/Writeup 行 46px → 34px，操作按钮悬停显现。
  • 修改历史：卡片式（每条约66px）→ 单行式（约32px），操作「派生」悬停显现；「当前/源版本」用左侧色条高亮。
  • 容器模拟测试：类型Tabs+下拉+按钮三段合并为一行工具条；测试卡头部压成一行，容器地址单行排列，剩余时间等宽字体防抖动。
  • 滚动策略：页面整体不滚动，仅标签内容区与右侧面板内部滚动，视野内信息密度更高。
  • 数据均为演示样例，仅用于查看布局密度。
